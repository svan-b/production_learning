🥁 DFAM (Drummer From Another Mother)

Essential Parameters

Parameter Range Quick Tip
VCO 1 Frequency 10 octaves Lower = deeper kicks (try 12-20 for kicks)
VCO 2 Frequency 10 octaves Slightly higher than VCO1 for punch
VCO Decay Fast to Slow Shorter = punchier drums
Noise Level 0-100% 10-20% for attack click, 70%+ for hi-hats
VCF Cutoff 20Hz - 20kHz Sweep for tonal variation
VCF Decay Fast to Slow Controls brightness envelope

Kick Drum Recipe

  • VCO 1: Low (10-20)
  • VCO 2: Slightly higher
  • VCO Decay: Short-Medium
  • Noise: 10-15%
  • Filter: Mid-range, moderate decay

Snare Recipe

  • VCO 1: Mid-high (40-60)
  • VCO 2: Slightly detuned
  • VCO Decay: Short
  • Noise: 60-80%
  • Filter: Open, fast decay

🎹 Mother-32

Key Specifications

Parameter Range/Type Notes
VCO Waveforms Saw, Pulse Pulse has variable width
LFO Range 0.1 - 600 Hz Can be used as 2nd oscillator
Filter Cutoff 17Hz - 21.5kHz 24dB/oct Moog ladder
Attack Time 1.25ms - 3000ms Part of ADSR/ASR envelope
Decay/Release 1.25ms - 7000ms Switchable modes
Sequencer 32 steps, 64 presets Records note, glide, gate, accent, rest, ratchet

Essential Patches

  • Vibrato: LFO → VCO CV
  • Filter Sweep: EG → VCF Cutoff
  • Wobble Bass: LFO → VCF Cutoff
  • FM Bass: LFO → VCO (high rate)

Signal Flow

  • VCO → Mixer
  • Mixer → VCF → VCA
  • LFO/EG modulate parameters
  • 32-point patchbay for routing

🌊 Subharmonicon

Polyrhythm System

Component Function Usage
2 VCOs Main oscillators Base tones for subharmonics
4 Subharmonic Oscillators Mathematical divisions (÷1 to ÷8) Create harmonic relationships
4 Rhythm Generators Clock dividers (÷1 to ÷16) Create polyrhythms
2 x 4-step Sequencers Pattern generators Triggered by rhythm gens
Filter 4-pole ladder (-24dB/oct) Classic Moog tone shaping

Polyrhythm Ideas

  • Simple: RG1=4, RG2=3 (3:4 polyrhythm)
  • Complex: RG1=5, RG2=4, RG3=7
  • Sync Point: Patterns align at LCM
  • Start simple, add complexity gradually

Subharmonic Tips

  • ÷2 = octave below
  • ÷3 = fifth below (12 semitones)
  • ÷4 = two octaves below
  • ÷5 = major third (17 semitones)

🎼 Analog Four MKII

Elektron Sequencer Workflow

Feature How It Works Tip
Parameter Locks Hold TRIG + turn knob Different sound per step
Conditional Trigs Probability-based triggers 100%, 75%, 50%, 25%, 12.5%
Sound Locks Different sound per step Creates variation in patterns
Micro-timing Shift notes slightly Adds groove and swing

Quick Start

  • GRID RECORDING mode for parameter locks
  • Hold TRIG + adjust knobs
  • Use conditional trigs for variation
  • Pattern chain for song structure

Sound Design

  • 4 voices of analog synthesis
  • Subtractive + FM capabilities
  • Multimode filter
  • Extensive modulation matrix

🔊 Xone:96 Mixer

Signal Flow & EQ Settings

Section Specification Usage
Channels 1-4 EQ 4-band asymmetric HI/LO: +6dB/-∞ | MID: +10dB/-27dB
Channels A/B EQ 3-band parametric HI/LO: +6dB/-∞ | MID: +10dB/-24dB (swept)
USB Soundcard Dual 24ch, 96kHz 6 stereo in/out per card
Sends 2 stereo sends Send 1: pre/post switchable
Returns 4 stereo returns For external FX

Signal Path

  • INPUT → GAIN → EQ
  • EQ → FILTER → FX SENDS
  • SENDS → CHANNEL FADER
  • FADER → CROSSFADER → MASTER

Best Practices

  • Meter post-EQ, pre-fade
  • Use filters for creative transitions
  • Master insert for bus processing
  • Send 1 also routes to USB 9/10

Complete Technical Specifications

Detailed specifications for all your gear, sourced from official manuals.

🥁 DFAM

  • ✓ Two analog VCOs (triangle/square waves)
  • ✓ 10-octave frequency range per VCO
  • ✓ White noise source
  • ✓ 4-pole transistor ladder filter (switchable LP/HP)
  • ✓ Three decay envelopes
  • ✓ 8-step analog sequencer
  • ✓ 24-point patchbay (3x8)
  • ✓ Eurorack compatible (60hp, 319x107mm)
  • ✓ External audio input

🎹 Mother-32

  • ✓ Single VCO (saw + pulse with PWM)
  • ✓ LFO: 0.1 - 600 Hz (triangle + square)
  • ✓ 24dB/oct Moog ladder filter (LP/HP modes)
  • ✓ Filter range: 17Hz - 21.5kHz
  • ✓ Envelope: Attack 1.25-3000ms, Decay/Release 1.25-7000ms
  • ✓ ADSR and ASR modes
  • ✓ 32-step sequencer, 64 preset slots
  • ✓ Sequencer records: note, glide, gate length, accent, rest, ratchet
  • ✓ 32-point patchbay
  • ✓ Eurorack compatible (60hp)

🌊 Subharmonicon

  • ✓ 6-tone sound engine (2 VCOs + 4 subharmonic oscillators)
  • ✓ Subharmonic divisions: ÷1 to ÷8
  • ✓ 4-pole (-24dB/octave) Moog ladder filter
  • ✓ 4 rhythm generators (÷1 to ÷16)
  • ✓ 2 x 4-step sequencers
  • ✓ 2 Attack/Decay envelopes (VCF and VCA)
  • ✓ 32-point 1/8" patchbay
  • ✓ Polyrhythmic sequencing
  • ✓ Eurorack compatible (360mA from +12V)

🎼 Analog Four MKII

  • ✓ 4-voice analog synthesizer
  • ✓ Subtractive + FM synthesis
  • ✓ Multimode filter per voice
  • ✓ Parameter locks per step
  • ✓ Sound locks per step
  • ✓ Conditional trigs (100%, 75%, 50%, 25%, 12.5%)
  • ✓ Micro-timing for groove
  • ✓ Pattern chaining
  • ✓ Extensive modulation matrix
  • ✓ Performance macros

  • ✓ 64-step sequencer

  • ✓ 40 knobs, 74 switches

🔊 Xone:96

  • ✓ 6+2 channel analog DJ mixer
  • ✓ CH 1-4: 4-band EQ (HI/LO: +6dB/-∞, MID: +10dB/-27dB)
  • ✓ CH A/B: 3-band parametric EQ (swept mid)
  • ✓ Dual 24-channel USB soundcards (32-bit/96kHz)
  • ✓ 2 stereo sends, 4 stereo returns
